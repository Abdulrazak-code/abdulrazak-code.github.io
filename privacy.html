Privacy Policy

Last updated: 2 November 2026

Razak's Studio Uploader is a personal tool used only by its owner to manage the owner's own YouTube channels.

What it accesses

  • YouTube Data API: to upload videos, set their titles, descriptions and thumbnails, and read their status on the owner's channels.
  • YouTube Analytics API (read-only): to read views and watch time of the owner's channels.

What it stores

The sign-in token is stored only on the owner's computer. No data is sent to any server other than Google's.

What it shares

Nothing. No data is sold, shared or used for advertising. It does not access anyone else's account.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
